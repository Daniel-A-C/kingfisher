# Kingfisher Antigravity Plugin

Automatically keeps local `.kingfisher.yaml` task boards synchronized with Antigravity coding sessions.

## What's Included

- **Always-On Rule (`rules/AGENTS.md`)**: Reminds Antigravity to check `.kingfisher.yaml` / `kf next --json`, move tickets to `active` when starting work, and automatically move them to `done` with `agent_notes` once verified.
- **Skill (`skills/kingfisher-tasks/SKILL.md`)**: Full reference for `kf` CLI commands (`init`, `next`, `list`, `move`, `capture`, `add`) and the `.kingfisher.yaml` board schema.
- **Logo (`assets/logo.svg`)**: Art Nouveau Kingfisher crest icon.
